# Windows System Administration: Disk Management and Encryption

## Overview

In this lab, I configured and managed a new storage disk in Windows Server and secured the drive using BitLocker. I practiced disk management, volume creation, encryption, recovery, and decryption.

**Lab Platform:** Pluralsight
**My Work:** Completed the hands-on lab environment, performed the configurations, tested the functionality, and documented the process with screenshots and step-by-step notes.

## Objectives

### Objective 1 — Partitioning and Formatting Drives

* Bring an offline disk online
* Initialize the disk using GPT
* Create a 10 GB NTFS volume
* Assign the volume to the **D:** drive
* Verify the new storage

### Objective 2 — Enabling BitLocker and Configuring Recovery

* Copy files to the new D: drive
* Enable BitLocker encryption
* Configure a BitLocker password
* Create and save a recovery key
* Verify the encrypted drive

### Objective 3 — Testing Encryption and Decryption

* Lock the BitLocker-protected drive
* Unlock the drive using a password
* Unlock the drive using the recovery key
* Verify file accessibility
* Decrypt the drive and remove BitLocker protection
